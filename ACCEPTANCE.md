# Приемка 0.2.0-rc.3, 17 ноября 2026

## Поставка и приватность

Образ пересобран без Git provenance и Git labels. Перед созданием ZIP
проверены все файловые слои, OCI-метаданные и файлы пакета. Состав пакета
ограничен явным списком. Результат проверки образа находится в privacy.json
внутри ZIP, пределы проверки описаны в [docs/PRIVACY.md](docs/PRIVACY.md).

В бесплатном образе нет модуля Multi и исходных .py приложения. Обратный
разбор байткода не исключается. Контрольные суммы находятся в checksums.json.
Установщик этого RC не подписан издателем.

## Mocks

- Проверены 54 теста Python и 7 тестов Node. При первом общем прогоне один
  браузерный тест завершился ошибкой навигации при лимите 600 мс; отдельный
  повтор прошел. Успешность первого прогона целиком не заявляется.
- Готовый Free-образ проверен через Windows-пакет при отключенной внешней
  сети: две записи собраны дважды, в SQLite остались две уникальные записи.
- Проверены JSON, UTF-8/Base64, HTTP-импорт, авторизация, недоверенный Origin,
  чужой контекст и ограничение одной организацией.
- Неудачный сбор не удаляет прежние mock-записи. Повторная инициализация
  сохраняет настройки, поврежденный пакет отвергается.
- Собственные контейнеры приемки остановлены. Фоновые задачи не создавались;
  существующие установки не обновлялись.

Результаты: [acceptance.mock.json](acceptance.mock.json).
