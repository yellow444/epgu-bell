# Приемка 0.2.0-rc.1, 13 ноября 2026

Все приведенные результаты относятся к mocks. Живой портал, новая
авторизация с ЭП и PROD в этой самостоятельной поставке не проверялись.

- Исходники: 40 тестов Python и 7 тестов Node прошли.
- Готовый Free-образ: настоящий headless Chromium при отключенной внешней
  сети получил две записи дважды; SQLite сохранила две уникальные записи.
- Локальный API: два импорта вернули 201, после каждого осталось две записи.
  Запрос без токена, недоверенный Origin и чужой контекст отвергнуты.
- Смена организации при повторном запуске отвергнута установщиком и самим
  скомпилированным Free-приложением. Истекшая сессия не удалила прежние записи.
- Windows: ZIP распакован в новый обычный пользовательский каталог.
  Нативный установщик проверил SHA256, загрузил архив образа, создал отдельную
  установку, запустил demo/API и остановил только свой контейнер.
  Повторная инициализация сохранила настройки; испорченный пакет отвергнут.
- Free-образ не содержит исходных .py приложения и модуля Multi.
  Возможность обратного разбора байткода не исключается.
- Закрытый Multi-образ: две организации обработаны дважды, по одной
  уникальной записи в каждой базе. Одинаковые внешние ID остались изолированы.

Существующие установки для этой приемки не использовались и не обновлялись. Эти результаты получены локально
до создания отдельных GitHub-репозиториев и публикации выпуска.

Машиночитаемый результат: acceptance.mock.json. Образ, установщик и документы
проверяются по checksums.json внутри готового пакета.
