# Приемка 0.2.0-rc.2, 16 ноября 2026

## Живой TEST

Проверка выполнена на собственной организационной сессии. Название,
реквизиты организации, идентификаторы объектов, сессия и выгрузки в
публичный отчет и поставку не включаются.

- Вход выполнен в обычном браузере. Сборщик получил отдельно подготовленную
  временную TEST-сессию; автоматический вход сборщика этим не подтверждается.
- Нативный Windows-установщик проверил SHA256 пакета, загрузил образ,
  создал отдельную установку и дважды выполнил Collect.
- Оба сбора завершились успешно. JSON прошел проверку схемы и хеша;
  содержимое двух снимков совпало.
- **Живая лента была пустой: 0 уведомлений.** Поэтому отсутствие дублей
  на непустой живой ленте, ее текстовые поля и Base64 этим не проверены.
- С пустой сессией сохранен валидный диагностический снимок
  `needs_user_action` с `feed_api_http_401`. Ошибка не выдается за пустую
  успешную ленту. После возврата сессии чтение восстановилось.
- Проверен API-адаптер списка, а не полный DOM/расширение, детали записей
  или вложения. Полнота всей ленты и влияние чтения на внешний статус
  прочитанности не подтверждены. PROD не проверялся.

Машиночитаемая граница: [acceptance.live-empty.json](acceptance.live-empty.json).

## Mocks

- Прошли 46 тестов Python и 7 тестов Node.
- Готовый Free-образ при отключенной внешней сети собрал две записи дважды;
  в SQLite осталось две уникальные записи. Проверены JSON, UTF-8/Base64,
  HTTP-импорт, авторизация, чужой контекст и ограничение одной организацией.
- Неудачный сбор не удалил прежние mock-записи.
- Закрытый Multi-образ дважды обработал две синтетические организации:
  в каждой базе осталась одна запись. Совпадающие внешние ID изолированы.
- Demo прошел отдельным запуском после загрузки образа. Один параллельный
  запуск во время загрузки образа завершился ошибкой; такой режим нагрузки
  не считается принятым.

Результаты mocks: [acceptance.mock.json](acceptance.mock.json).

В бесплатном образе нет модуля Multi и исходных .py приложения. Обратный
разбор байткода не исключается. Контрольные суммы файлов находятся в
checksums.json пакета. Установщик этого RC не подписан издателем.
Фоновые задачи при приемке не создавались; существующие установки не обновлялись.
