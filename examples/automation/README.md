# Подготовка автоматизаций без отправки

prepare_actions.py читает выходной JSON Bell через открытый клиент импорта,
сохраняет локальную очередь заготовок и пишет actions.json. Это код
получателя данных. Он не содержит реализацию закрытого сборщика, браузерный
вход, селекторы, сетевые методы портала или рецепты контейнеров.

Получатели: bitrix24, webhook, digest. Для Битрикс24 формируются параметры
поиска по внешнему ID и создания CRM-элемента, для webhook JSON события,
для digest обычный текст. Сетевого отправителя в этом примере нет.

Команды, настройки и ограничения:
[AUTOMATION_RECIPES.md](../../docs/AUTOMATION_RECIPES.md).

Проверка на синтетических данных:

```powershell
python -m unittest discover -s examples/automation -p 'test_*.py' -v
```

Проверены повторы без дублей, обновление заготовок, отказ при чужом контексте,
ошибке сессии, смене настроек, отсутствие сетевых вызовов и явное включение
текста. Живые порталы Битрикс24, экземпляры n8n и внешние отправки
не проверялись. Эти файлы входят в пакет rc.4; старый rc.3 не меняется.
