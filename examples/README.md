# Примеры для знакомства и интеграции

Все записи в snapshot.mock.json синтетические. Этот файл можно читать
и импортировать без авторизации на портале. Он содержит проверочные кавычки,
переносы строк, Unicode и текст, похожий на HTML. После декодирования его
нужно отображать обычным текстом.

- [snapshot.mock.json](snapshot.mock.json): полный пример снимка.
- [integrations/import_notifications.py](integrations/import_notifications.py):
  самостоятельный клиент к JSON/локальному API, Python 3.11+, стандартная библиотека.
- [integrations/test_import_notifications.py](integrations/test_import_notifications.py):
  проверки клиента на синтетических данных.
- [1c/BellReader.bsl](1c/BellReader.bsl): исходный пример общего серверного
  модуля. Пока не запускался в 1С; это не EPF/CFE.
- [automation/prepare_actions.py](automation/prepare_actions.py): подготовка
  заготовок Битрикс24, webhook и краткого оповещения. Без сетевой отправки,
  с локальными ключами повторного приема и без текста сообщений по умолчанию.

Код этих примеров не содержит реализацию закрытого сборщика. Он не выполняет
вход в кабинет, сбор ленты или оформление полномочий.

Команды и ограничения: [руководство по интеграциям](../docs/INTEGRATIONS.md).
Примеры входят в пакет rc.4. Старые ZIP предыдущих RC не меняются.
