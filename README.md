# EPGU Bell Free

Сборщик уведомлений Госуслуг для одной организации на установку.
JSON с UTF-8/Base64, SQLite без дублей и локальный HTTP API.
Бесплатная готовая поставка; исходники приложения и Multi закрыты.

**[Скачать 0.2.0-rc.4](https://github.com/yellow444/epgu-bell/releases/tag/v0.2.0-rc.4)**

В rc.4 добавлены постраничный сбор, курсор выгрузки накопленной базы,
схема снимков 1.3 и примеры интеграций. Windows x64 установщик и образ
linux/amd64 требуют Docker Desktop в режиме Linux containers.
Установщик не подписан издателем. Это проверочный выпуск для пилота.

Проверка текста документации и примеров перед коммитом:

```powershell
python tools/check_text_style.py
python tools/test_check_text_style.py
```

Синтаксис команд и тестовые данные проверка сохраняет. Для бейджей и символов
поддержки в корневом README сделано исключение.

Bell читает уведомления выбранного представления. Статус услуги нельзя
надежно определить только по их тексту. Полная история, тела и вложения,
автоматический вход и боевой контур пока не приняты.

## Проверить пакет без учетной записи

Из распакованного ZIP, в отдельном каталоге установки:

```powershell
$demoRoot = Join-Path $env:LOCALAPPDATA ('EPGU Bell Demo ' + [guid]::NewGuid().ToString('N'))
.\tools\epgu-bell-setup.exe Verify
.\tools\epgu-bell-setup.exe Load
.\tools\epgu-bell-setup.exe Initialize --organization-id ORG-DEMO --install-root "$demoRoot"
.\tools\epgu-bell-setup.exe Demo --install-root "$demoRoot"
```

Demo использует только синтетические записи и работает без внешней сети.
Существующие установки не обновляются и не перезаписываются.

Для проверки полного пути готового пакета есть публичный скрипт без зависимостей
от закрытого репозитория. Нужны Python 3.10+, Docker Desktop и распакованный ZIP:

```powershell
$checkRoot = Join-Path $env:LOCALAPPDATA ('Bell Free Check ' + [guid]::NewGuid().ToString('N'))
python examples/check_single_org.py --package C:/Downloads/BellFree --output "$checkRoot"
```

Он проверяет установку, headless Demo, JSON/Base64, локальный HTTP API,
постраничное чтение, повтор без дублей и отказ другой организации. Нужен
только Free-пакет, реальные сессии и Multi не подключаются. Скрипт останавливает
свой API-контейнер и удаляет свой временный токен. Рабочие установки не меняет.

## Своя организация

Для внешнего сбора настройте отдельную установку с собственным OID и сессией
по [SESSION.md](docs/SESSION.md). Затем используйте команды Collect, StartApi,
Status и Stop; список параметров доступен через `epgu-bell-setup.exe --help`.
Один Collect завершается после сбора. StartApi поднимает локальный API,
автоматического опроса сам не запускает. Порт публикуется на 127.0.0.1.

Настройки и данные по умолчанию находятся в %LOCALAPPDATA%/EPGU Bell.
Для нескольких независимых каталогов передавайте одинаковый --install-root
всем командам своей установки. Free закреплен за одной организацией и контуром
на каталог. Смена контекста отвергается. Multi не включен в Free.

## Получатель данных

[Клиент Python](examples/integrations/import_notifications.py) читает JSON
или локальный API, обходит страницы и сохраняет свою SQLite. Проверяемый
[генератор автоматизаций](examples/automation/README.md) готовит параметры
для Битрикс24, webhook и оповещений, но не выполняет внешние действия.
[BSL-пример](examples/1c/BellReader.bsl) еще не запускался в 1С и не является EPF/CFE.

Файлы session содержат секреты. Снимки и базы могут содержать сообщения.
Не добавляйте их в Git и публичные отчеты. Base64 не шифрует текст.

## Состав и хеши

В ZIP есть checksums.json для каждого файла и application-provenance.json
с хешем исходных входов сборки приложения. Сборка сверяет этот хеш с образом.
В релизе дополнительно размещены SHA256 архива и release-evidence.json,
который связывает публичный коммит документации, образ и хеш пакета.
Политика проверки: [PRIVACY.md](docs/PRIVACY.md).

В образе нет исходных py приложения и Multi, но байткод и клиентский
JavaScript допускают обратный анализ. Закрытая поставка не означает
техническую невозможность исследовать реализацию. Ограничение одной
организацией защищает от случайного смешения данных и не является DRM.
