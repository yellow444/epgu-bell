# EPGU Bell Free

Готовый сборщик внешних уведомлений Госуслуг для одной организации.
JSON с UTF-8/Base64, SQLite без дублей и локальный HTTP API. Бесплатная
поставка распространяется без публикации исходников приложения.

**[Скачать готовую сборку 0.2.0-rc.2](https://github.com/yellow444/epgu-bell/releases/tag/v0.2.0-rc.2)**

EXE в пакете — небольшой Windows-установщик. Он проверяет SHA256,
загружает Docker-образ, создаёт настройки и управляет контейнером своей
установки. Сбор уведомлений выполняется в Docker. Исходник установщика
хранится вместе с закрытым кодом приложения.

Версия **0.2.0-rc.2**, Windows с Docker Desktop в режиме Linux containers,
образ linux/amd64, установщик для Windows x64 на .NET Framework.
Политика выполнения PowerShell не меняется. Это проверочная поставка.
На живом TEST проверено чтение пустой организационной ленты с заранее
подготовленной собственной сессией, повторный сбор, отказ при истекшей
сессии и восстановление чтения. Живая лента содержала **0 уведомлений**:
дедупликация непустой живой ленты и ее текстовые поля пока не приняты.
Непустые записи, Base64 и отсутствие дублей проверены на mocks.
Автоматический вход, боевой контур и расширение на живом портале не приняты.

В API-режиме сборщик выполняет три GET-запроса: контекст, лента, контекст
повторно. Отрисовка страницы для этого не запускается. Ошибки HTTP,
включая 401, сохраняются как диагностический JSON со статусом
`needs_user_action`; прежние записи остаются в базе.

## Запуск из распакованного выпуска

Нужен пакет с `release.json`, `checksums.json` и архивом образа.

```powershell
.\tools\epgu-bell-setup.exe Verify
.\tools\epgu-bell-setup.exe Load
.\tools\epgu-bell-setup.exe Initialize --organization-id YOUR_TEST_ORGANIZATION_OID
.\tools\epgu-bell-setup.exe Demo
```

`Demo` работает в контейнере без внешней сети и не использует ваши реквизиты.
Сохраняет две синтетические записи дважды, проверяет отсутствие дублей,
HTTP-импорт, авторизацию, чужой контекст, ограничение одной организацией
и сохранность записей при потере сессии.

Для сбора своей ленты нужен отдельный файл состояния собственной браузерной
сессии. Подготовка описана в [docs/SESSION.md](docs/SESSION.md).

```powershell
.\tools\epgu-bell-setup.exe Collect
.\tools\epgu-bell-setup.exe StartApi --port 8778
.\tools\epgu-bell-setup.exe Status
.\tools\epgu-bell-setup.exe Stop
```

Одна команда сбора завершается; `StartApi` поднимает локальный приемник
и API явного сбора. Он не запускает автоматический опрос сам по себе.
API может принимать снимки без файла сессии; для `POST /v1/collect` сессия
нужна. Порт опубликован только на `127.0.0.1`.

По умолчанию данные лежат в `%LOCALAPPDATA%\EPGU Bell`. Для отдельной папки
передавайте одинаковый `--install-root` всем командам. Инициализация не
перезаписывает готовую установку. Файлы `session/` содержат секреты и не
включаются в резервные копии для публичного обмена.

## Граница бесплатной версии

- Один организационный OID и один контур на каталог установки. Смена
  организации при повторном запуске отвергается; локальный API не принимает
  переопределение контекста через запрос.
- Чтение полей списка и экспорт JSON. Полнота всей ленты, полное тело письма,
  скачивание вложений и неизменность внешней прочитанности не гарантируются.
- API не является API-Key ЕПГУ и не оформляет полномочия на услуги.
- В образе нет модуля нескольких организаций. Приватная версия обрабатывает
  отдельные конфигурации последовательно и хранит их базы отдельно.

Привязка защищает от случайного смешения данных. Она не является DRM:
владелец компьютера может создать другую установку или изменить файлы.
Отсутствие `.py` файлов не исключает обратный разбор байткода; браузерный
JavaScript парсера остается клиентским ресурсом. Закрытая поставка не
означает техническую невозможность исследовать ее содержимое.

Исходники и приватный модуль хранятся отдельно и могут предоставляться
владельцем выборочно. Этот репозиторий предназначен для документации,
установщика, контрактов и готовых выпусков. Экспериментальное расширение
сохранено в закрытом проекте; в этот Docker-пакет оно не входит.
