# Условия поставки

EPGU Bell Free предоставляется владельцем бесплатно для чтения уведомлений
одной организации на установку. Исходный код приложения не публикуется.
Исходники и версия для нескольких организаций распространяются отдельно.

Это проверочный выпуск 0.2.0-rc.3, а не подтверждение допуска к продуктивной
интеграции. Реальные сессии, ключи и уведомления в пакет не входят.

Приложение и сторонние компоненты имеют разных правообладателей.
Условия сторонних компонентов сохраняются; уведомления находятся в образе
рядом с пакетами зависимостей и в third_party. В частности, профиль seccomp
взят из Playwright v1.61.0 с сохранением исходного уведомления.

Контрольные суммы служат проверке целостности данного пакета и не заменяют
подпись издателя. Готовые выпуски публикуются в GitHub Releases репозитория
https://github.com/yellow444/epgu-bell. Исходники приложения и Multi
в этот публичный репозиторий не входят.
