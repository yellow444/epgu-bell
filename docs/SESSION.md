# Собственная сессия

Этот выпуск не входит на Госуслуги автоматически и не переносит ключи.
Файл `state.json` создается самим пользователем в отдельном браузерном
профиле. Он содержит Cookie и другие секреты сессии.

Если вы используете Playwright, его штатный `codegen --save-storage`
позволяет сохранить состояние после ручного входа. На отдельном доверенном
компьютере с Python и установленным Playwright соответствующей версии:

```powershell
python -m pip install playwright==1.61.0
python -m playwright install chromium
python -m playwright codegen --save-storage="$env:LOCALAPPDATA\EPGU Bell\session\state.json" https://svcdev-betalk.test.gosuslugi.ru/notifications
```

В открывшемся окне пользователь сам проходит обычный вход и выбирает нужную
организацию. После этого закрывает окно браузера, чтобы состояние сохранилось.
Криптоплагин, сертификат и MFA могут требовать другого поддерживаемого
браузера: штатный codegen не заменяет их и не обходит требования входа.
Свежая авторизация этим способом на живом TEST в новой поставке не проверена.

Для своего `InstallRoot` используйте его подкаталог `session`. Существующие
рабочие профили, особенно Docker-стенд EPGU, этой инструкцией не изменяются.
Не отправляйте state.json в поддержку и не добавляйте его в Git.

Сборщик проверяет активный организационный контекст до и после чтения.
Если сессия истекла или выбрана другая роль, результатом будет
`needs_user_action`; накопленные уведомления останутся в базе. Авторизуйтесь
повторно для той же организации и замените только собственный state.json.
