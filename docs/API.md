# Локальный HTTP API

Адрес после `StartApi`: `http://127.0.0.1:8778` (порт настраивается).
Токен хранится в `session/api-token.txt` выбранной установки. Передавать
`Authorization: Bearer <токен>` всем методам кроме `/health`.

| Метод | Результат |
| --- | --- |
| GET /health | Готовность процесса, без персональных данных |
| GET /v1/capabilities | edition=free, max_organizations=1 и ограничения чтения |
| GET /v1/snapshots/latest | Последний снимок, включая ошибку сессии |
| GET /v1/notifications | До 1000 накопленных записей с first_seen_at/last_seen_at |
| POST /v1/collect, тело {} | Сбор только заранее настроенного контекста |
| POST /v1/snapshots/import | Проверка и сохранение снимка того же контекста |
| POST /v1/outbox/deliver, тело {} | Передача в заранее настроенный получатель |

GET не запускает внешний сбор. Неизвестные browser Origins отвергаются.
Локальный API не принимает URL, другую организацию или путь сессии через POST.
Импорт проверяет согласованность присланного снимка, а не доказывает внешний
кабинет независимо от клиента. Отдельной ролевой модели пользователей нет:
токен дает доступ к данным единственной организации этой установки.

Схемы 1.0/1.1/1.2 описаны в snapshot.schema.json. Контекст Free относится
только к организации; личный снимок не совпадет с конфигурацией и будет
отвергнут. Текст и дополнительные API-поля записываются в Base64 UTF-8.
Base64 не шифрует данные. При отображении использовать textContent.

`coverage.complete=false` сохраняется и при `hasMore=false`: ответ относится
к текущей странице и фильтрам. `external_unread_count` может быть null.
Число записей в SQLite не является глобальным числом непрочитанных.
